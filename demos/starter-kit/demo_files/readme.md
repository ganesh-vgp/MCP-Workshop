# Demo Files

These are test files for the MCP server demo.

## Files included:

- `hello.txt` - Simple greeting file
- `numbers.txt` - List of numbers 1-10
- `readme.md` - This file

## Usage:

Your MCP server should be able to:

1. **List these files** using the `list_files` tool
2. **Read file contents** using the `read_file` tool  
3. **Write new files** using the `write_file` tool
4. **Serve as resources** so AI models can access them directly

## Testing:

Use the test client to verify your implementation:

```bash
python test_client.py
```

Good luck with your MCP server implementation! 🎯
